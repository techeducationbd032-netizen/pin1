# CWFPIN

CWFPIN creates complete CoreWellFit Pinterest content after a mandatory fresh review of the Core Well Fit Pinterest profile.

Typical request:

> Create 10 CoreWellFit Pinterest pins for Health & Fitness → Morning Routines. Analyze my Pinterest profile first, then create the true JPEGs, metadata, PPTX, and store everything in Google Drive.

The skill automatically completes the batch, validates exactly eight hashtags per description, verifies true 1000×1500 JPEG output, creates one pin per PPTX slide, and organizes the deliverables.
