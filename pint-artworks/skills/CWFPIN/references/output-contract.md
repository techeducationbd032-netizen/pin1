# Output Contract and QA Checklist

## Batch folder

```
CoreWellFit Pinterest/
  YYYY-MM-DD/
    topic-slug/
      profile-analysis.md
      metadata.md
      pin-01.jpg
      batch-YYYY-MM-DD_HH-MM-SS_BDT.pptx
      source/
        pin-01.png
```

## Profile analysis record

Include:

- Date and time reviewed
- Profile URL
- Access method
- Access limitations
- Current positioning
- Current boards/topics observed
- Visual and keyword patterns
- Duplication risks
- Content gap selected
- Reason the topic fits the audience

## Metadata record per pin

- Category
- Subcategory
- Topic
- Pin Title
- Description
- Hashtag count: 8
- Alt Text
- JPEG filename
- JPEG MIME type
- Dimensions
- PPTX filename
- Destination links

## Final QA

- [ ] Fresh Pinterest analysis completed
- [ ] Access limitation recorded honestly
- [ ] Topic complements current content
- [ ] Graphic copy is spelled correctly
- [ ] JPEG is genuine image/jpeg
- [ ] JPEG is exactly 1000×1500
- [ ] Title is search-friendly and within platform limits
- [ ] Description contains exactly eight unique hashtags
- [ ] Alt text describes visible content
- [ ] PPTX has one pin per slide
- [ ] PPTX opens and has no text overflow
- [ ] All requested files are stored successfully
- [ ] Final links point to the correct files
